# 🎵 Music Market Application

Music Market is a multi-layered C# application designed to manage music-related data and operations. It follows a modular architecture, separating concerns across different layers for better maintainability and scalability.

## 🚀 Technologies Used

- C#
- .NET Framework
- ASP.NET Web API
- Entity Framework
- SQL Server

## 🧱 Project Structure

- **Music.Market.Api**: Handles HTTP requests and serves as the entry point of the application.
- **Music.Market.Core**: Contains core entities and interfaces.
- **Music.Market.Data**: Implements data access using Entity Framework.
- **Music.Market.Services**: Contains business logic and service implementations.

## 🎯 Features

- CRUD operations for music entities
- RESTful API endpoints
- Layered architecture for separation of concerns
- Database integration with Entity Framework
